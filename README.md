# FishTux / TuxBrowser 🐧🛡️

**TuxBrowser** — быстрый, легковесный и бескомпромиссно защищённый веб-браузер для Linux с маскотом Tux, встроенным анонимным роутингом **Tux Ghost** (Tor с поддержкой WebTunnel и obfs4), защитой от фингерпринтинга и локальным поисковым движком **TuxFind**.

---

## ✨ Ключевые возможности

### 👻 1. Tux Ghost (Анонимность и обход блокировок)
- **Tor Network Routing:** Встроенное управление изолированным процессом Tor без необходимости ручной настройки.
- **Поддержка Pluggable Transports:** Поддержка **WebTunnel**, **obfs4/lyrebird** и **Snowflake** для надёжного обхода DPI-блокировок.
- **Мгновенная смена личности (New Identity):** Ротация выходных нод и IP в один клик через Tor Control Port.
- **Пользовательские прокси:** Поддержка внешних SOCKS5 и HTTP(S) прокси.

### 🛡️ 2. Анти-фингерпринтинг и Защита Приватности
- **Tux Privacy Shield:** Блокировка рекламы, майнеров, Google Analytics, Яндекс.Метрики и трекеров на уровне сетевых запросов.
- **Precision Timezone Alignment:** Автоматическая синхронизация системного часового пояса JavaScript (`Intl.DateTimeFormat`, `Date.prototype.*`, `getTimezoneOffset`) с GeoIP активного выходного узла Tor / прокси для предотвращения утечек локации.
- **WebRTC & DNS Leak Protection:** Защита от утечек реального IP через WebRTC и DNS prefetching.
- **Canvas & Audio Noise Injection:** Защита от снятия уникальных цифровых отпечатков Canvas и AudioContext.

### 🔍 3. Встроенный поисковый движок TuxFind
- Высокопроизводительный локальный метапоисковый сервис на Go.
- Параллельный опрос источников (DuckDuckGo, Wikipedia) с нулевым логированием запросов и IP.

### 🌐 4. Встроенные системные страницы `tux://`
- `tux://home` — Стартовая страница с пингвином Tux, виджетами и быстрым поиском.
- `tux://shield` — Центр безопасности и статистика заблокированных угроз.
- `tux://settings` — Тонкая настройка приватности, мостов Tor, поисковых систем и профиля.
- `tux://history` — Локальная история с фильтрацией и защитой.
- `tux://bookmarks` — Менеджер закладок.

## 🚀 Запуск и Установка

### Требования:
- Python 3.10+
- PySide6 (`pip install -r browser/requirements.txt`)
- Go 1.20+ (для сборки TuxFind)
- `tor` и `webtunnel-client` / `lyrebird` (опционально, для обхода блокировок)

### Запуск:
```bash
# Установка зависимостей Python
pip install -r browser/requirements.txt

# Сборка поискового движка TuxFind (опционально, бинарник уже доступен)
cd TuxFind && go build -o tuxfind main.go && cd ..

# Запуск браузера:
./tux-browser

# Запуск в приватном режиме (Ghost Mode):
./tux-browser --ghost
```

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
|---|---|
| `Ctrl + T` | Новая вкладка |
| `Ctrl + W` | Закрыть вкладку |
| `Ctrl + Shift + T` | Восстановить закрытую вкладку |
| `Ctrl + L` / `Alt + D` | Фокус на адресную строку |
| `Ctrl + R` / `F5` | Обновить страницу |
| `Ctrl + Shift + N` | Открыть приватное окно Tux Ghost |
| `Ctrl + H` | История |
| `Ctrl + B` | Закладки |
| `Ctrl + J` | Загрузки |
| `F11` | Полноэкранный режим |
