# TuxBrowser 🐧 (Linux Security Edition)

Легковесный, защищённый браузер с маскотом Linux — пингвином Tux.

## 🛡️ Ключевые возможности безопасности и приватности

1. **Tux Privacy Shield:**
   - Встроенный перехватчик запросов (`TuxRequestInterceptor`) для блокировки Google Analytics, Яндекс.Метрики, Facebook Pixel, баннерных сетей и майнеров до отправки сетевого запроса.
   - Динамический счетчик заблокированных угроз в адресной строке в реальном времени.
   - Быстрый белый список для доверенных сайтов.
2. **HTTPS-Only и Инспекция SSL:**
   - Автоматическое повышение безопасности протоколов.
   - Цветовая индикация статуса шифрования (Зеленый замок для TLS 256-bit, Предупреждение для HTTP).
3. **Изоляция и Защита Данных:**
   - Песочница процессов Chromium.
   - Блокировка сторонних cookies (Cross-site tracking).
   - Принудительная отправка заголовков `DNT` (Do Not Track) и `Sec-GPC`.
   - Режим приватного окна **Ghost Mode** (работа только в RAM, нулевой след на диске).
4. **Встроенные схемы `tux://`:**
   - `tux://home` — Стартовая страница с пингвином Tux, виджетами и быстрым поиском.
   - `tux://shield` — Центр безопасности и статистика блокировок.
   - `tux://settings` — Настройки приватности и движка.
   - `tux://history` — История с поиском и очисткой.
   - `tux://bookmarks` — Менеджер закладок.
   - `tux://about` — О браузере.

## 🚀 Запуск

```bash
# Обычный запуск:
./tux-browser

# Запуск в приватном режиме (Ghost Mode):
./tux-browser --ghost

# Открытие конкретного URL:
./tux-browser https://kernel.org
```

## ⌨️ Горячие клавиши

- `Ctrl+T` — Новая вкладка
- `Ctrl+W` — Закрыть текущую вкладку
- `Ctrl+Shift+T` — Восстановить закрытую вкладку
- `Ctrl+L` / `Alt+D` — Перейти в адресную строку
- `Ctrl+R` / `F5` — Обновить страницу
- `Ctrl+H` — История посещений
- `Ctrl+B` — Панель закладок
- `Ctrl+J` — Список загрузок
- `Ctrl+Shift+N` — Приватное окно Tux Ghost
- `Ctrl+F` — Поиск на странице
- `Ctrl + / - / 0` — Масштабирование
- `F11` — Полноэкранный режим
